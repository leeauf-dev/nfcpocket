# Changelog

Notable changes are documented here. This project follows [Semantic Versioning](https://semver.org/).

## [Unreleased]

### Changed

- Android application ID and namespace changed to `com.leeauf.pocketnfc`
- Releases are now manually triggered and always use the persistent project signing key

## [0.1.0] - 2026-09-04

### Added

- NFC Forum Type 4 Tag emulation for NDEF URL records
- Local link history, favorites, editing, and last-used timestamps
- Android Share Target for browser links
- NFC/HCE capability status and NFC settings shortcut
- Material 3 light, dark, and dynamic-color themes
- Android and iPhone receiver support for standard NDEF URLs
