# Changelog

Notable changes are documented here. This project follows [Semantic Versioning](https://semver.org/).

## [Unreleased]

## [1.1.0] - 2026-09-04

### Added

- Three-step first-run guide
- Clipboard URL detection and automatic HTTPS normalization
- Search, swipe-to-delete, duplicate, copy, share, and open actions
- Read counter, persistent emulation sessions, and contextual NFC help
- Quick access to the last-used URL

### Changed

- Clearer NFC capability and emulation feedback
- Larger controls and improved accessibility labels

## [1.0.0] - 2026-09-04

### Changed

- Android application ID and namespace changed to `com.leeauf.pocketnfc`
- Releases are manually triggered and use the persistent project signing key

## [0.1.0] - 2026-09-04

### Added

- NFC Forum Type 4 Tag emulation for NDEF URL records
- Local link history, favorites, editing, and last-used timestamps
- Android Share Target for browser links
- NFC/HCE capability status and NFC settings shortcut
- Material 3 light, dark, and dynamic-color themes
- Android and iPhone receiver support for standard NDEF URLs
